# 📊 Sales Performance Dashboard – Excel

## Project Overview

This project is an **Excel Sales Performance Dashboard** created to analyze sales, quantity, cost, profit, products, categories, regions, and customer revenue.

The dashboard provides an interactive view of business performance using **Pivot Tables, Pivot Charts, Slicers, and KPI cards**.

## 📌 Key KPIs

* **Total Sales:** 26,29,365
* **Total Quantity Sold:** 219
* **Total Orders:** 80
* **Total Cost:** 18,49,361
* **Total Profit:** 7,80,004

## 📈 Dashboard Analysis

The dashboard includes:

* Monthly Sales Analysis
* Sales by Category
* Sales by Region
* Sales by Product
* Quantity Sold by Product
* Top 5 Customers by Revenue
* Total Sales KPI
* Total Quantity Sold KPI
* Total Orders KPI
* Total Cost KPI
* Total Profit KPI

## 🎛️ Interactive Filters

Users can filter the dashboard using:

* **Order Date**
* **Product**
* **Category**

These slicers make it easy to explore specific periods, products, and categories.
